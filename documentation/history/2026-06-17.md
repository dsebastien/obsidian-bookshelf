# 2026-06-17

## Issue #4 — toggle off shelf textures and shadows

Added two view-option toggles so users can get a "less decorations" bookshelf:

- `showShelf` ("Shelf decorations", default `true`) — when off, the shelf renders as a flat surface using `--background-secondary`, with the wood/stone texture, front ledge (`::after`), surface shadow line (`::before`), and shelf box-shadow all removed. Bottom padding drops from 56px to 24px since there's no ledge.
- `showShadows` ("Book shadows", default `true`) — when off, removes the per-book grounding shadow (`.bookshelf-book::before`), the 3D hardcover box-shadows on `.bookshelf-book-cover` (and its hover state), and the bottom-edge `::after`. A thin `inset 0 0 0 1px` border is kept so covers stay readable.

### Implementation

- `src/app/view/view-options.ts` — added two `toggle` options before the shelf material dropdown.
- `src/app/view/bookshelf-view.ts` — read both config values and set `data-shelf-decorations` / `data-book-shadows` (`'on'`/`'off'`) on the container.
- `src/styles.src.css` — added a "MINIMAL MODE" block after the texture rules. The `[data-shelf-decorations='off'] .bookshelf-shelf` selectors share specificity (0,2,0) with the `[data-shelf-texture='…']` rules, so they must stay after them in source order to win. The hover override uses 0,3,0 and beats the base hover rule.
- `docs/configuration.md` — documented the new "Decorations" section.

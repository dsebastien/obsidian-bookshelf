# 2026-11-18

## Default covers (issue #15)

Books without a usable cover image now get a CSS-drawn hardcover with foil lettering instead of the colored spine block.

- Design options page: `documentation/designs/default-covers.html` (options, palettes, spine view, proposal). Chosen: cloth as default; leather, library, mixed and classic as options. Art deco dropped (weak at small sizes).
- New module `src/app/view/default-cover.ts` + `default-cover.spec.ts`: `hashTitle` (moved from `generateSpineColor`, same output), palettes, `resolveCoverStyle`, `pickCoverColor`, `pickLabelColor`, `longestWordLength`, `formatAuthor`, `stripWikilink`, `spineAuthor`, `coverAriaLabel`, option normalizers.
- `bookshelf-view.ts`: `renderDefaultCover`, `readAuthor` (ListValue aware), `onCoverImageError` (probe with `new Image()`; a dead URL now falls back to the default cover; this was the "empty spot" of the issue).
- New view options: `defaultCover`, `authorProperty`, `coverFoil`. See `documentation/Configuration.md`.
- CSS: section "DEFAULT COVERS" in `styles.src.css`. Container queries for scaling, spine layout (aspect < 2/5) and small cards. Textures are inline SVG noise (black, alpha only) + gradients.
- `test-setup.ts`: mock `ListValue`.
- Business rules for covers added to `documentation/Business Rules.md`.
- Screenshots: `docs/assets/bookshelf-screenshot.png` (new hero, real Obsidian capture), `default-cover-*.png`.

## Decisions

- Colors from fixed dark palettes, not HSL: gold has no contrast on light HSL colors.
- `classic` keeps the old look exactly (same hash, same HSL), and is the "off" switch.
- No `default` on the `authorProperty` option: an unset value lets the view try `author` then `authors`.
- Spine text runs bottom to top, like the classic spine.
